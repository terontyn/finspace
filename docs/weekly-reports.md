# Недельные отчёты и напоминания

Backend строит недельный отчёт по календарной неделе workspace и сравнивает её с
предыдущей. Доходы, расходы, баланс, top categories и остатки всегда группируются по
валютам; суммы разных валют не складываются. В отчёт также входят количество черновиков,
операций без категории, ближайшие recurring rules, состояние синхронизации и backup.

Отчёт создаётся только для пользователей с активной Telegram-привязкой и включённым
`weekly_report`. Длинный текст разбивается на сообщения короче лимита Telegram. Audit
хранит период и статус, но не полный финансовый текст.

Отдельный ежедневный отчёт `uncategorized_reminder` ничего не отправляет при нулевом
числе операций. Настройки канала, события, времени и timezone пользователь меняет в
разделе **Telegram**.

```powershell
.\scripts\weekly-report-test.ps1 -ServiceKey $serviceKey -WorkspaceId $workspace
```

Повторный запрос с тем же `X-Idempotency-Key` возвращает сохранённый результат
`automation_run` и не дублирует отправку.
