# Текущее состояние проекта
Финансовое ядро, импорт, бюджеты/прогнозы, регулярные правила, цели, контрагенты, категоризация, сверка и закрытие месяца реализованы backend-кодом и интерфейсами. Google Sheets использует Apps Script Bridge; n8n и Telegram — необязательный внешний контур.

Текущая миграция: 0017_categorization_history. Источник поддерживаемой области — [supported-scope.md](supported-scope.md), порядок приёмки — [release.md](release.md). Состояние конкретной серверной установки и приватные access/evidence identifiers в публичной документации не хранятся.

Присутствие кода и тестов не заменяет release evidence. Перед эксплуатацией необходимы изолированный PostgreSQL suite, UI проверки, migration/performance gates и проверенные off-host backup/clean restore для точного релизного SHA. Эти операционные подтверждения должен предоставить владелец установки.
