# Посмотреть интерфейс без рабочих данных
Демо запускает существующий Next.js UI с явно отдельным read-only HTTP adapter. Все счета, суммы, пользователь и контрагент вымышлены. Нет PostgreSQL, банковских подключений, Google, Telegram или n8n. Этот режим не проверяет финансовые инварианты backend.

```sh
cd frontend
npm ci
cd ..
node demo/run.mjs
```

Нужны Node 22+ и Python 3.12+. Откройте http://127.0.0.1:8791. Поддерживаются обзор, список операций, счета и категории. Операции записи отклоняются; остальные экраны честно сообщают, что не входят в demo. Оба процесса слушают loopback. Строка demo-session-not-a-credential — фикстура adapter, не JWT рабочего backend. Без явного NEXT_PUBLIC_DEMO_MODE основной UI не включает demo-режим.

Для настоящего создания/редактирования и интеграций используйте [локальную разработку](local-development.md), отдельную тестовую БД и полный backend. Демо не является production-установкой.
